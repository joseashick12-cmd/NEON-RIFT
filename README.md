# NEON RIFT — Battle for the Core

Godot 4 mobile-first 3D neon arena prototype. This repository contains the game source and a GitHub Actions workflow to attempt an Android test APK build.

## Build APK
1. Open the **Actions** tab.
2. Select **Build NEON RIFT Android APK**.
3. Click **Run workflow**.
4. When it succeeds, download the `NEON-RIFT-Android-APK` artifact and extract `NEON_RIFT.apk`.

The first build is not yet verified. This is a test build, not a Play Store release. Multiplayer and Android device behaviour require testing.

## Run locally
Open `project.godot` in Godot 4.4 or newer and press F6/F5. Controls: WASD/arrow keys to move, Space to jump, Shift to dash.
