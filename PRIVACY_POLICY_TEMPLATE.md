## Data collection

The prototype has no accounts, advertising SDKs, analytics SDKs, in-app purchases, or voice chat. Online play processes IP addresses and network metadata to connect devices. The optional room directory receives a host IP address, port, room code, and expiry time. Room entries are held in server memory until expiry or restart.

## Purpose and sharing

Network information is used for game connections and private-room lookup. The directory operator and hosting provider may process connection metadata. No sale of personal information is intended.
